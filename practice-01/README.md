## Задание 1. Один файл — две среды выполнения

Файл `js/hello.js` был запущен двумя способами:

1. Через Node.js (терминал): команда `node practice-01/js/hello.js`.
   - Вывод появился в терминале VS Code.
   - Последняя строка: `Тип document: undefined` (в Node.js нет объекта document).

2. Через браузер: открыт файл `index.html`, вывод смотрели через инструменты разработчика (F12 → Console).
   - Вывод появился в консоли браузера.
   - Последняя строка: `Тип document: object` (в браузере document — это HTML-страница).

Вывод: один и тот же файл работает в обеих средах, но результат `typeof document` различается, потому что в Node.js нет DOM-модели, а в браузере есть

## Задание 2. Исследование типов и преобразований

Файл `js/types.js` запущен в Node.js и в браузере. Результаты совпали.

| № | Выражение          |  Значение  | Тип результата | Объяснение                                                          |
|   |                    |            |                |                                                                     |
| 1 | `"8" + 2`          | `"82"`     | string         | Оператор `+` при наличии строки склеивает числа                     |
| 2 | `"8" - 2`          | `6`        | number         | Оператор `-` приводит строку к числу, тк работает только с числами  |
| 3 | `Number("8") + 2`  | `10`       | number         | Преобрзование строки в число + сложение                             |
| 4 | `"12" > "3"`       | `false`    | boolean        | Строки сравниваются по поряду: `"1" < "3"`                          |
| 5 | `12 === "12"`      | `false`    | boolean        | Сравнение                                                           |
| 6 | `Number("")`       | `0`        | number         | Пустая строка преобразуется в 0                                     |
| 7 | `Number("text")`   | `NaN`      | number         | Нечисловая строка → NaN (тип всё равно number)                      |
| 8 | `Boolean("false")` | `true`     | boolean        | Любая непустая строка → true                                        |
| 9 | `typeof null`      | `"object"` | string         | Историческая особенность JavaScript                                 |
| 10 | `typeof NaN`      | `"number"` | string         | NaN имеет тип number                                                |
